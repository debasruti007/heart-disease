# Heart Disease Risk Screener (P4)

**Team:** Pawar & Debasruti
**Project:** Heart-disease risk screener with a regularized MLP

A deep learning system that estimates heart disease risk from 13 clinical
features, built from a from-scratch perceptron and MLP through to a
regularized Keras model, served via a FastAPI backend and a Streamlit
web app.

**⚠️ This tool is a screening aid, not a medical diagnosis.**

---

## Live deployment

- **Web app:** https://heart-disease-pr2ys9yqxjthpqcehq3idf.streamlit.app/
- **API:** https://heart-disease-api-cnbx.onrender.com

Note: the API is hosted on Render's free tier, which sleeps after 15
minutes of inactivity. The first request after idling takes 30-60 seconds
to wake up; after that it responds normally.

## How to run (in order)

Each script depends on files created by the one before it. Run them in
this order the first time:

```bash
# 1. Data pipeline (downloads Cleveland data, cleans, encodes, splits)
python src/data_prep.py

# 2. Perceptron from scratch (4 activations, cross-validated)
python src/perceptron.py

# 3. MLP from scratch, with a gradient check against numerical derivatives
python src/mlp_scratch.py

# 4. Same MLP in Keras, verified to match the scratch version's predictions
python src/mlp_framework.py

# 5. Deliberate overfitting demo + dropout/batchnorm ablation table
python src/mlp_ablation.py

# 6. Threshold tuning, calibration plot, final ONE-TIME test-set evaluation
#    (saves models/final_model.keras and models/threshold.joblib, used by the API)
python src/evaluate.py

# 7. Generalization test: train on Cleveland, test on Hungary
python src/generalization_test.py
```

Every script above logs its results to `experiments/results.csv`.

## Model summary

- **From scratch:** Perceptron (step/sigmoid/tanh/linear) and a full MLP
  with backpropagation, implemented in NumPy only. Verified against a
  Keras model built with identical weights (`mlp_framework.py`'s match
  check) and against numerical gradients (`mlp_scratch.py`'s gradient
  check).
- **Final architecture:** MLP, hidden layers [128, 64], dropout 0.4 +
  batch normalization, chosen from a 4-way ablation
  (none / dropout only / batch norm only / both) that showed dropout
  contributing most of the regularization benefit on this small dataset.
  See `experiments/results.csv` and `report/figures/` for the full
  ablation table and plots.
- **Evaluation:** 5-fold stratified cross-validation used throughout
  (dataset has only 303 patients). Threshold tuned on out-of-fold
  predictions to reach recall ≥ 0.85. Test set touched exactly once,
  in `evaluate.py`.
- **Generalization:** tested on the Hungarian dataset (different
  hospital, heavy missingness in `ca`/`thal`/`slope`) — see
  `generalization_test.py` output for the resulting drop in performance
  and discussion.

## API

`POST /predict` — takes the 13 raw clinical fields, returns:
- `risk_probability`
- `risk_band` (Low / Moderate / High)
- `flagged_for_review` (based on the tuned threshold)
- `top_contributing_features` (per-patient perturbation-based explanation)
- a mandatory screening-aid disclaimer

`GET /health` — status check.

Full interactive docs available at `/docs` on the running API
(e.g. https://heart-disease-api-cnbx.onrender.com/docs).
